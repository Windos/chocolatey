# Chocolatey Packages

Packages maintained by Josh King

## Layout

- `_auto` - packages updated automatically by the Choco Auto Update workflow
- `_manual` - packages updated by hand
- `_deprecated` - deprecated packages, kept so their final version can be republished if needed
- `_icons` - package icons
